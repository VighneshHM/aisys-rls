Every defect found while building and testing, with severity, steps to reproduce, owner, status, where it was fixed and how it was
retested. At the time of writing **no defect is open**.

**Legend.** Severity: **High** (data loss or corruption, security exposure, a scenario cannot be completed), **Medium** (wrong result
with a workaround, or a feature degraded), **Low** (wording, layout, convenience). Status: **Open** (found, not fixed), **Fixed**
(fixed and retested; the retest evidence column says how), **Won't fix** (none so far). **Owner** is the developer, VighneshHM,
working with the AI assistant. **Fixed in** gives the pull request, the branch and the version: every fix is in the `0.1.0` line (the
`version` in `pyproject.toml`) before the evaluation tag. Pull request numbers come from the merge history (`git log --merges`): #21 and #22 both
merged the branch `overall-fixes`, #21 on 2026-10-09 (`3b11886`) and #22 later that day (`2a1681c`), so a defect fixed in a commit
after `3b11886` is credited to #22. Defects D-047 to D-054 were fixed on the branch `fix/sop-gaps` and merged in PR #23 (D-052 amended in PR #24). D-055 to
D-061 were found by the second SOP coverage review and fixed on the branch `fix/review-gaps`, whose pull request is
numbered when it is opened; D-062 to D-080 were found by the functional, hostile-input, permission and UI test
pass of 2026-10-10 (a code review, an automated probe of every route and a browser sweep at desktop and phone
widths) and fixed on the same branch. **Steps to reproduce** are the observable
trigger taken from each defect's description; they were not re-run for this log, they describe the original discovery.
