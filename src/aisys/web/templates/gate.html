What passes the gate

The gate reads the security bit on every tag. A tag whose bit is still on and that is not on loan raises an alarm: the accession number is recorded, a CCTV snapshot is taken, and a message is queued for each person who asked for alerts. The decision comes from the tag itself, so the gate works even when the library system is down.
